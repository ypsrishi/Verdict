VERDICT — BREVO EMAIL OTP (PYTHON BACKEND)

1. Install Python 3.11+
2. Open a terminal in this folder.
3. Run: python -m venv .venv
4. Activate: .venv\Scripts\activate
5. Run: pip install -r requirements.txt
6. Copy .env.example to .env
7. Put your Brevo API key ONLY in .env:
   BREVO_API_KEY=YOUR_REAL_BREVO_API_KEY
8. Keep .env out of GitHub. It is already in .gitignore.
9. Start: python -m uvicorn app:app --host 127.0.0.1 --port 8000
10. Open: http://127.0.0.1:8000

Brevo sender:
BREVO_FROM_EMAIL=thokesehoaap@gmail.com
BREVO_FROM_NAME=Verdict
BREVO_REPLY_TO=thokesehoaap@gmail.com

The backend sends OTPs through Brevo's HTTPS API. The API key never belongs in HTML/JS.
